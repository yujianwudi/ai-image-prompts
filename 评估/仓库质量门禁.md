# 仓库质量门禁

这个文件记录本仓库后续持续优化时必须守住的检查项。  
目的：模板越加越多，也不能变乱、断链接、丢安全约束。

## 本地检查命令

```powershell
python 工具/check_prompt_repo.py
```

检查内容：

- 必要目录是否存在：角色、模板、示例、评估、参考仓库、工具、预览图。
- 必要文件是否存在：README、角色索引、模板索引、参考仓库追踪、核心模板文件。
- Markdown 是否为空或疑似编码损坏。
- README 和文档中的本地链接、图片引用是否存在。
- 角色文件是否保留“非低俗 / 不性感化 / 不要混入”的安全与防串约束。
- 参考仓库追踪清单是否包含三个外部 awesome-gpt-image-2 仓库。
- 预览图是否存在，是否过大。

## GitHub Actions

已添加 `.github/workflows/validate.yml`。  
每次 push 或 pull request 都会运行：

```bash
python 工具/check_prompt_repo.py
```

如果脚本报错，说明本次改动可能有断链、缺文件或安全约束遗漏，应该先修再合并。

## 新增内容前的人工检查

新增角色：

- 是否有发型、发色、头饰、服装、道具、气质。
- 是否有专属防串词。
- 是否明确非低俗、不性感化。

新增模板：

- 是否能放进已有分类，避免乱建文件。
- 是否用自然语言分段，而不是堆关键词。
- 如果包含文字生成，是否写了“短标题、清晰可读、不要乱码”。
- 如果是多格图，是否写了“同一角色一致性”。

新增预览图：

- 是否适合公开 README 展示。
- 是否压缩过。
- 是否没有水印、乱码、真实商标或低俗暗示。

# 失败修正词库

这个文件由 `工具/validate_failure_fix_lexicon.py` 根据 `评估/failure_fix_lexicon.json` 生成。
这里记录常见失败类型、识别线索和对应修正写法。
适合 gpt-image-2 的写法是自然语言约束，不是单纯堆 negative prompt。

- 规则版本：`2026-06-10`
- 规则数量：10

## 使用方式

1. 先在出图评分里记录具体问题。
2. 到本文件找到对应失败类型。
3. 复制“修正”里的自然语言约束做编辑或重生成。
4. 如果要新增失败类型，修改 `评估/failure_fix_lexicon.json`，再运行：

```powershell
python 工具/validate_failure_fix_lexicon.py
```

## 1. 角色串到芙宁娜

- ID：`furina_contamination`
- 分类：`character_consistency`
- 严重级别：`high`
- 适用角色：citlali、dori
- 后续动作：`edit`
- 识别线索：白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服、水神舞台女王气质

问题：

```text
非芙宁娜角色出现白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服或水神舞台女王气质。
```

修正：

```text
当前角色不是芙宁娜。不要出现白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服、水滴宝石和水神舞台女王气质。请严格保持当前角色的发型、头饰、服装体系和气质。
```

## 2. 发型发色错误

- ID：`wrong_hair_color`
- 分类：`role_anchor`
- 严重级别：`high`
- 适用角色：all
- 后续动作：`edit`
- 识别线索：发色错误、发长错误、辫子丢失、头饰位置错误

问题：

```text
角色发型、发色、刘海、辫子、卷曲程度或头饰位置偏离角色锚点。
```

修正：

```text
发型是角色识别重点。请严格保持：{正确发型描述}。不要改变发长、发色、刘海、辫子、卷曲程度和头饰位置。
```

- 严重级别：`high`
- 适用角色：all
- 后续动作：`edit`
- 识别线索：普通日常服、服装简化、配色丢失、标志性道具丢失

问题：

```text
角色 cosplay 服装被简化成普通日常服，缺少头饰、腰饰、道具或标志性配色。
```

修正：

```text
服装必须保持角色 cosplay 结构，不要简化成普通日常服。请保留头饰、领口、袖口、腰饰、下装、道具和标志性配色，材质要真实。
```

## 4. 多格图角色漂移

- ID：`multi_panel_drift`
- 分类：`consistency_layout`
- 严重级别：`high`
- 适用角色：all
- 后续动作：`edit`
- 识别线索：九宫格漂移、分镜角色不一致、多格图发型变化、服装配色变化

问题：

```text
九宫格、分镜板、角色卡等多区域图中，同一角色在不同格子里发型、服装、配色或气质漂移。
```

修正：

```text
所有格子都必须是同一个角色。每格只改变姿势、表情、镜头或场景，不改变发型、头饰、服装配色、关键配件和气质。
```

- 识别线索：乱码、随机英文、水印、logo、长段文字

问题：

```text
海报、信息图、UI 或封面中的文字乱码、随机英文、伪水印、伪 logo 或长段小字不可读。

```

## 10. 裁切错误

- ID：`bad_crop`
- 分类：`composition`
- 严重级别：`medium`
- 适用角色：all
- 后续动作：`edit`
- 识别线索：裁掉帽子、裁掉手部、鞋子不可见、关键道具被裁切

问题：

```text
全身图、半身图或角色卡构图裁掉头饰、手部、鞋子、关键服装结构或道具。
```

```text

```

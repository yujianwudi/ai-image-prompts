# 失败修正词库

这里记录常见失败类型和对应修正写法。  
适合 gpt-image-2 的写法是自然语言约束，不是单纯堆 negative prompt。

## 1. 角色串到芙宁娜

问题：

```text
非芙宁娜角色出现白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服或水神舞台女王气质。
```

修正：

```text
当前角色不是芙宁娜。不要出现白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服、水滴宝石和水神舞台女王气质。请严格保持当前角色的发型、头饰、服装体系和气质。
```

## 2. 发型发色错误

修正：

```text
发型是角色识别重点。请严格保持：{正确发型描述}。不要改变发长、发色、刘海、辫子、卷曲程度和头饰位置。
```

## 3. 服装变普通衣服

修正：

```text
服装必须保持角色cosplay结构，不要简化成普通日常服。请保留头饰、领口、袖口、腰饰、下装、道具和标志性配色，材质要真实。
```

## 4. 多格图角色漂移

修正：

```text
所有格子都必须是同一个角色。每格只改变姿势、表情、镜头或场景，不改变发型、头饰、服装配色、关键配件和气质。
```

## 5. 画面低俗或擦边

修正：

```text
画面必须端庄自然，非低俗，不性感化，不擦边。不要暴露服装、性感姿势、卧室暧昧感、泳装化或内衣化。适合公开GitHub README展示。
```

## 6. 文字乱码

修正：

```text
如果需要文字，只使用少量短中文标签，文字必须清晰可读。如果不能保证清晰文字，就不要生成任何可读文字。不要乱码、随机英文、水印或logo。
```

## 7. 手部或道具错误

修正：

```text
手部动作自然，五指清晰，道具拿法合理。道具不要遮挡脸，不要变形，不要和手融合。角色专属道具必须保持准确。
```

## 8. 背景太乱

修正：

```text
背景保留真实环境感，但必须轻微虚化，不要抢主体。减少无关物体、乱码招牌、杂乱人群和强烈干扰色。
```

## 9. 过度棚拍，不像手机随手拍

修正：

```text
画面像朋友用手机随手拍下的真实照片，不是专业棚拍，不是商业大片。保留轻微生活感、真实室内光线和自然构图。
```

## 10. 裁切错误

修正：

```text
请保持完整构图。全身图需要从头到脚完整入镜，鞋子可见；半身图需要头饰和上半身服装完整，不要裁掉帽子、手部或关键道具。
```

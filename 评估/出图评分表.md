# 出图评分表

总分 100 分。  
80 分以上可以考虑放入 README 或示例；低于 70 分建议继续迭代。

| 项目 | 分值 | 检查点 |
| --- | ---: | --- |
| 角色一致性 | 25 | 发型、发色、头饰、服装体系、配件、气质是否属于同一角色 |
| 构图与比例 | 15 | 是否9:16，主体是否完整，是否裁切错误，画面是否清楚 |
| 服装材质 | 15 | 布料、刺绣、金属扣、宝石、皮革、发丝是否真实 |
| 场景匹配 | 10 | 场景是否符合模板，背景是否自然，不抢主体 |
| 安全与公开性 | 15 | 是否非低俗、不性感化、无擦边、适合公开展示 |
| 文字与UI | 10 | 如果有文字，是否清晰可读；如果不需要文字，是否无乱码 |
| 交付可用性 | 10 | 是否适合放入 README、示例或作为模板效果图 |

## 结构化记录

如果要把评分结果沉淀成可被脚本校验的数据，可以复制：

```text
评估/output_evaluations.example.json
```

校验命令：

```powershell
python 工具/validate_output_evaluations.py --check
python 工具/summarize_output_evaluations.py --check
```

结构化记录会检查总分、Prompt Pack、角色、图片路径、公开安全状态、问题列表和下一步动作，方便后续统计哪些模板最容易失败。
`评估/出图评分汇总.md` 会自动汇总平均分、决策分布和常见问题。

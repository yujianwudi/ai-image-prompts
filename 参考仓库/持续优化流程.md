# 持续优化流程

目标：定期根据参考仓库更新本仓库，但不直接复制长提示词。

## 每次迭代步骤

```text
1. 查看三个参考仓库最近更新
2. 只记录新增类别、版式、输出类型和常见失败点
3. 判断本仓库是否已有对应模板
4. 如果已有，只补充一小段结构或修正词
5. 如果没有，再新增分类模板
6. 更新 README / CHANGELOG / 参考仓库追踪清单
7. 提交并同步 GitHub
```

## 提炼规则

### 可以提炼

- 分类名称。
- 版式结构。
- 输出类型。
- 变量位置。
- 常见失败点。
- 安全约束。
- 多格图一致性规则。

### 不要直接复制

- 其他仓库的长提示词原文。
- 作者署名之外的完整案例文案。
- 完整图片描述。
- 商业品牌或真实商标的可复用广告文案。

## 更新频率建议

```text
轻量更新：每周一次，补分类和修正词。
集中更新：每月一次，整理新的模板文件。
大版本更新：当 gpt-image-2 官方参数或 API 行为有变化时。
```

## 每次更新检查清单

- [ ] README 是否能指向新增内容。
- [ ] 模板文件是否分类清楚。
- [ ] 示例是否可以直接复制。
- [ ] 是否有非低俗、安全公开约束。
- [ ] 是否避免直接搬运外部长 prompt。
- [ ] CHANGELOG 是否记录。

# 优秀 gpt-image-2 仓库提炼：模板优化方向

参考仓库：

- https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts
- https://github.com/freestylefly/awesome-gpt-image-2
- https://github.com/YouMind-OpenLab/awesome-gpt-image-2

这个文件只做结构提炼，不直接搬运原仓库里的长提示词。  
目标是把它们的常见成功模式，改造成适合本项目的可复用模板。

## 1. 三个仓库共同高频类型

### 写实人像 / 角色摄影

常见关键词不是单纯「高质量」，而是：

- 明确照片来源：手机抓拍、CCD闪光、35mm胶片、杂志编辑片、街拍、直播截图。
- 明确环境：便利店、咖啡馆、夜街、商场、展馆、地铁、校园、甜品店。
- 明确构图：半身、全身、回头、九宫格、拼贴、杂志封面。
- 明确真实质感：皮肤纹理、发丝、衣服褶皱、金属高光、背景噪点。

### 电商 / 广告 / 海报

高频结构是：

- 主产品或主角色居中。
- 背景搭一个小型品牌世界或主题场景。
- 画面里有层次：前景道具、中景主体、背景氛围。
- 适合做九宫格分镜、TVC storyboard、商品卖点拆解图。

### 信息图 / UI / 社媒截图

高频结构是：

- 需要明确版式，不只是画面风格。
- 需要指定文字区域、图标区、卡片区、数据区。
- 如果有文字，要写「短标题、少量标签、文字清晰可读、不要乱码」。
- 适合做技术解释图、产品功能图、社媒帖子、直播间界面、App界面。

### 角色卡 / 分镜 / 设定集

高频结构是：

- 角色参考卡、角色介绍页、表情九宫格、服装拆解图、战斗姿势设定。
- 需要固定角色锚点，避免多格图里发型和服装漂移。
- 适合给本项目的芙宁娜、茜特菈莉、多莉做「角色设定卡」和「多图风格统一」。

### 内容包装 / 封面 / 教程 / 地图

高频结构是：

- 封面缩略图需要强主体、短标题、高对比、预留文字区。
- 长图教程和 Slides 需要固定网格、短标签、图标区和留白，不适合塞长段正文。
- 地图导览需要明确“示意图”定位，区域、路线和编号比真实地理精度更重要。
- 文字越多越容易出错，所以优先使用短中文标题、短标签和清晰留白。

## 2. 对本项目的优化结论

原模板偏「单张写实照片」。  
现在补充四类：

1. **商业海报 / 电商模板**：适合把角色做成活动海报、周边海报、甜品店联名视觉。
2. **信息图 / UI / 社媒模板**：适合做角色设定说明页、Prompt使用教程图、社媒封面。
3. **角色卡 / 分镜模板**：适合做角色一致性、多姿势、多表情、多服装展示。
4. **防漂移约束**：多格图必须重复强调同一角色的发型、头饰、服装体系和气质。
5. **内容包装模板**：补充封面缩略图、教程长图、Slides 和地图导览，方便把提示词库做成公开传播素材。
6. **Prompt as Code字段化**：把任务类型、主体锁定、版式构图、文字策略和防串约束拆成可复用字段。

## 3. gpt-image-2 优化后的通用输出类型

使用时先选一个输出类型：

```text
输出类型：写实照片 / 电商主图 / 广告海报 / 信息图 / UI截图 / 社媒帖子 / 角色设定卡 / 分镜板 / 九宫格拼贴
```

再填内容：

```text
主体：
{角色专属提示词}

场景：
{场景模板}

版式：
{单图 / 九宫格 / 左右分栏 / 上图下文 / 海报中心构图 / UI卡片布局}

重点：
{发型、服装、头饰、道具、材质、气质}

约束：
同一角色保持一致，不混入其他角色设定，不低俗，不乱码，不水印。
```

## 4. 多格图防漂移规则

九宫格、分镜、角色设定卡最容易漂移。  
每次都要加这一段：

```text
所有格子都必须是同一个角色，保持完全一致的发色、发型长度、头饰、服装配色、关键配件和气质。每一格只改变姿势、镜头、表情或背景，不改变角色身份。
```

如果是茜特菈莉或多莉，再加：

```text
不要混入芙宁娜的白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服和水神舞台女王气质。
```

## 5. 文字类画面防乱码规则

信息图、海报、UI截图里如果需要文字：

```text
只使用少量短中文标题和短标签。文字必须清晰可读，不要乱码，不要随机英文，不要水印，不要多余logo。文字区域留白充足，版式干净。
```

如果不需要文字：

```text
不要生成任何可读文字，不要logo，不要水印，不要乱码。
```

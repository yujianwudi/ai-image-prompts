# 封面缩略图模板

适合做 YouTube / B站 / 小红书 / GitHub README 封面图。  
重点是：一眼看懂主题、主体清楚、文字少、对比强，但不要做成低俗标题党。

## 1. 横版视频封面

```text
生成一张16:9横版视频封面图。

主体：
{角色专属提示词}

主题：
{视频/文章主题，例如“gpt-image-2角色防串教程”}

画面：
角色位于画面右侧或中间，表情自然有记忆点；左侧预留大标题区域。背景是{场景}，有轻微景深和明暗层次。

文字：
只使用一个短中文标题，文字清晰、粗体、对比强，不要乱码，不要随机英文，不要平台logo。

约束：
端庄自然，非低俗，不性感化，不夸张擦边，不水印。角色发型、头饰、服装体系和气质必须准确，不混入其他角色元素。
```

## 2. 竖版社媒封面

```text
生成一张9:16竖版社媒封面图。

主体：
{角色专属提示词}

版式：
上方是短标题区，中间是角色半身或三分之二身，下方是2-3个短标签卡片。整体像干净的教程封面或模板展示封面。

风格：
写实cosplay照片结合简洁图文排版，背景明亮，有真实服装材质和轻微现场感。

文字：
短标题不超过8个字，标签不超过4个字。文字清晰可读，不要乱码、错字、随机英文和真实平台logo。

安全：
适合公开发布，非低俗，不性感化，不卧室暧昧感。
```

## 3. README 项目头图

```text
生成一张适合 GitHub README 顶部展示的横版头图，比例约 16:9。

内容：
展示“AI生图提示词模板库”的感觉：左侧是简洁标题区和模板卡片，右侧是{角色专属提示词}的端庄写实cos预览。

视觉：
干净、现代、有文件夹和模板卡片的视觉元素；色彩克制，像项目文档封面，不像夸张广告。

约束：
不要真实品牌logo，不要水印，不要乱码。角色设定准确，服装材质真实，整体适合公开仓库。
```

## 4. 缩略图避坑

- 不要一次放太多字，标题越短越稳。
- 不要写夸张低俗表情和姿势。
- 不要让文字压住角色关键识别点。
- 角色封面要先保证发型、头饰、服装准确，再追求冲击力。

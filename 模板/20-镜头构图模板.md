# 3. 镜头 / 构图固定模板

## 3.1 半身正面

```text
半身正面构图，角色从头到腰部入镜，脸部、发型、帽子和上半身服装最清晰，背景轻微虚化，手机竖图，适合强化头饰、眼睛和表情
```

## 3.2 全身站姿

```text
全身站姿构图，角色从头到脚完整入镜，服装轮廓、裙摆、裤装、鞋子和道具都能看到，9:16竖图，背景留出少量空间，姿势自然端庄
```

## 3.3 近景头像

```text
近景头像构图，肩部以上入镜，重点表现眼睛、妆容、发丝、头饰和表情，背景高度虚化，真实皮肤纹理，手机拍摄感，不要过度磨皮
```

## 3.4 三分之二身

```text
三分之二身构图，从头到大腿或膝盖入镜，兼顾表情、上半身服装和部分下装，适合角色服装复杂但不需要全身鞋子的场景，手机竖图，画面自然
```

## 3.5 轻微低角度

```text
轻微低角度手机拍摄，镜头略低于眼睛但不夸张，角色显得更有存在感，背景展馆灯光向上延伸，注意保持脸部自然不变形，非性感化角度
```

## 3.6 轻微俯拍

```text
轻微俯拍手机视角，镜头略高于角色眼睛，角色微微抬头看向镜头，表情自然，适合可爱、害羞、安静的气质，但不要幼态化，不要低俗
```

## 3.7 回头抓拍

```text
角色听到朋友叫名字后回头，身体微微侧向前方，脸转向镜头，发丝和服装边缘有轻微动感，手机随手拍，真实抓拍感，背景人群虚化
```

## 3.8 侧身看镜头

```text
角色侧身站立，一只手自然放在腰侧或整理配件，脸转向镜头，构图自然，服装轮廓清晰，适合展示侧面发型、帽子和腰部配饰
```

## 3.9 道具互动

```text
角色拿着专属小道具，手部动作自然，道具位于胸前或腰侧，不遮挡脸，镜头聚焦角色和道具，背景虚化，真实手部细节，避免畸形手指
```

## 3.10 人群中主体清晰

```text
角色位于画面中央，周围有模糊人群经过，主体清晰，背景轻微运动模糊，像漫展现场真实抓拍，9:16竖图，强调真实感和现场感
```

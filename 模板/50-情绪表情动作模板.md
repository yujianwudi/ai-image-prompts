# 6. 情绪 / 表情 / 动作固定模板

## 6.1 自然微笑

```text
自然微笑，眼神看向镜头，表情不夸张，像熟人拍照时放松地笑了一下，适合大多数角色
```

## 6.2 被朋友喊住回头

```text
被朋友喊住后回头看镜头，表情带一点惊讶和自然反应，身体还保持行走或转身姿势，真实抓拍感
```

## 6.3 稍微害羞

```text
稍微害羞但不幼态，眼神柔和，嘴角轻微上扬，一只手自然整理头饰或头发，端庄安全，不低俗
```

## 6.4 自信展示

```text
自信展示服装，一只手轻轻展开披帛或整理外套，表情从容，像coser在漫展中配合朋友拍照，不商业棚拍
```

## 6.5 安静冷淡

```text
安静冷淡的表情，眼神平静，嘴角不明显上扬，姿势克制，适合神秘、巫女、萨满、冷色系角色
```

## 6.6 活泼招呼

```text
活泼地抬手打招呼，笑容明亮，身体微微前倾但姿势安全端庄，适合可爱、商人、元气角色
```

## 6.7 整理帽子

```text
一只手轻轻扶着帽檐或整理头饰，另一只手自然下垂或拿道具，帽子和发型清晰，表情自然
```

## 6.8 拿饮料休息

```text
角色拿着饮料杯在休息区放松，表情有点疲惫但开心，服装保持完整，生活感强，像漫展逛累后被朋友拍下
```

## 6.9 看向摊位

```text
角色侧头看向展位或周边，眼神没有直视镜头，画面像偷拍式生活抓拍，背景摊位虚化，服装细节仍清晰
```

## 6.10 道具展示

```text
角色把专属道具拿在胸前或身侧展示，表情自然，手部动作合理，道具清楚但不挡脸，适合强化角色识别度
```

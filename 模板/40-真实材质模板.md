# 5. 真实材质固定模板

## 5.1 服装真实质感总模板

```text
真实服装材质，布料有自然褶皱，缝线清晰，刺绣有轻微立体感，金属扣和链条有真实反光，宝石不是塑料，皮革有细微纹理，服装边缘有真实厚度
```

## 5.2 缎面 / 礼服

```text
缎面布料有柔和高光，深色布料不糊成一片，白色布料不过曝，金色扣件和宝石有真实反光，适合贵族礼服和舞台感服装
```

## 5.3 编织布 / 部落纹样

```text
编织布纹理清晰，几何纹样像真实刺绣或织花，飘带和披帛有布料重量感，珠饰和小吊坠有真实阴影，适合萨满、部落、民族风服装
```

## 5.4 商人服饰 / 饰品

```text
商人风服装有丝绸、棉布、皮革和金属混合质感，金币、钱袋、宝石、眼镜和帽子装饰都清晰但不过度夸张，适合须弥商人风
```

## 5.5 头饰强化

```text
头饰清晰可辨，帽子轮廓完整，发饰不融进头发，金属和宝石细节真实，头饰位置准确，不变成其他角色的帽子
```

## 5.6 发丝真实感

```text
发丝分层清晰，发色准确，刘海和侧发束自然垂落，发尾有轻微蓬松，避免发丝变成塑料块，避免错误发色和错误发长
```

## 5.7 手部与道具

```text
手部自然，五指清晰，道具拿法合理，道具不遮挡脸，专属道具保持角色设定，避免手指畸形、手部融合、道具变形
```

## 5.8 鞋子 / 下装

```text
全身图时保持鞋子和下装完整，脚部不被裁切，裤装或裙摆有真实重力和褶皱，鞋子材质清楚，避免下半身服装串角色
```

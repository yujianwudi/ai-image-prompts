# 10. 联网参考

这些模板是基于常见 AI 生图提示词结构整理出来的，并按你的「写实 cos、9:16、非低俗、真实服装质感」需求重写过，不直接复制网上长模板。

## 2026-06-10 复核摘要

本次重点查了 OpenAI 官方图片生成文档和图片提示词 Cookbook，把模板优化成更适合 `gpt-image-2` 的写法：

- 使用自然语言分段，不只堆关键词。
- 先明确输出用途，再写主体、场景、构图、光线、材质和约束。
- 角色防串任务里，主体锁定要放在前面，发型、头饰、服装体系和气质都要具体。
- 写实照片要明确「手机照片、普通观众视角、真实光线、真实材质」。
- 带文字的海报、信息图、UI，只写短标题和短标签，并要求清晰可读、不要乱码。
- 图像编辑提示词要拆成「保留 / 修改 / 不要修改」。
- OpenAI 参数和 Midjourney 参数分开写，不要把 `--ar`、`--style raw` 当成 OpenAI API 参数。

## 参考方向

- OpenAI 图片生成文档：确认模型、尺寸、质量、输出格式、编辑等 API 能力。  
- OpenAI 图片提示词 Cookbook：提炼自然语言分段、输出用途、关键细节、约束和文字生成策略。  
- Midjourney 参数文档：提示词参数通常放在末尾，常用 `--ar` 控制比例，`--style raw` 减少自动风格化。  
- Black Forest Labs / Flux 提示词建议：更适合用自然语言把图像类型、主体、场景、风格、相机、灯光、色彩说清楚。  
- Hugging Face / Diffusers 相关提示词资料：负面提示词可以帮助模型避开不想要的风格、质量问题和错误元素。  
- EvoLinkAI 的 awesome 仓库：分类里覆盖电商、广告创意、人像摄影、海报、UI、角色设计、对比测试等，适合提炼「输出类型优先」的模板结构。
- freestylefly 的 awesome 仓库：把模板整理成 UI、信息图、海报、商品、电商、品牌、摄影、角色、叙事、文档等工业级类别。
- YouMind-OpenLab 的 awesome 仓库：高频覆盖头像、YouTube 缩略图、漫画/故事板、社媒帖子、产品营销、信息图、电商主图等类别。

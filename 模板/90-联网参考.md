# 10. 联网参考

这些模板是基于常见AI生图提示词结构整理出来的，并按你的「写实cos、9:16、非低俗、真实服装质感」需求重写过，不是直接复制网上模板。

- Midjourney 参数文档：提示词参数通常放在末尾，常用 `--ar` 控制比例，`--style raw` 减少自动风格化。  
- Black Forest Labs / Flux 提示词建议：更适合用自然语言把图像类型、主体、场景、风格、相机、灯光、色彩说清楚。  
- Hugging Face / Diffusers 相关提示词资料：负面提示词可以帮助模型避开不想要的风格、质量问题和错误元素。  
- OpenAI gpt-image-2 提示词指南：更强调清楚描述场景、主体、构图、光线、材质和约束，适合把关键词模板改成自然语言分段说明。

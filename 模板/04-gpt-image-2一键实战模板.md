# gpt-image-2 一键实战模板

这个文件放「可以直接复制改变量」的模板。
2026-06-10 二次联网复核后，模板统一成：**任务模式 → 不可变主体锚点 → 必须保留 → 可变画面 → 文字策略 → 安全与防串约束 → 出图自检**。

## 0. 使用规则

每次只选一个模板，不要把所有模板混在一起。
把 `{变量}` 替换成你的角色、场景或标题即可。

通用变量：

```text
{角色专属提示词}
{必须保留的角色识别点}
{场景}
{构图}
{光线}
{材质}
{短标题}
{不要混入的角色元素}
{错误角色元素}
{新场景}
```

### 推荐 API 口径

```text
model: gpt-image-2
size: 1024x1824
quality: medium
output_format: jpeg
background: opaque
```

说明：`1024x1824` 更接近 9:16；`1024x1536` 是 2:3 备选，不要当成严格 9:16。

### 联网优化口径

- 写实照片：明确「手机照片 / 普通观众视角 / 自然光 / 真实材质 / 不过度磨皮」。
- 角色防串：把发型、头饰、服装体系、关键配件和气质放在最前面。
- 多格图：强调「所有格子是同一个角色，只改表情、角度或场景」。
- 带文字图：只用短标题和短标签；必须写清楚不要乱码、水印和真实 logo。
- 编辑图：分成「保留 / 修改 / 不要修改」，不要只写一句「修好」。
- 安全：端庄自然、非低俗、不性感化、不儿童化，尤其多莉必须成年化表达。

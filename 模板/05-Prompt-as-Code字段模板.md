# Prompt as Code 字段模板

参考 `freestylefly/awesome-gpt-image-2` 的 Prompt as Code 思路，本文件把提示词拆成稳定字段。  
目的不是让提示词更复杂，而是让每次生成都能知道“哪里该改，哪里不能动”。

## 1. 字段化总模板

```text
任务类型：
{写实cos手机随手拍 / README预览图 / 商业海报 / 电商主图 / 信息图 / UI截图 / 角色卡 / 分镜 / 封面缩略图 / 长图教程 / 地图导览}

主体锁定：
{角色专属提示词，必须包含发型、发色、头饰、服装体系、关键配件、气质}

场景环境：
{地点、背景元素、真实现场感、是否有路人/展位/玻璃反光/城市灯光}

版式构图：
{9:16竖图 / 16:9横图 / 1:1方图 / 三视图 / 九宫格 / 左右分栏 / 上图下文 / 地图俯视}

光线色彩：
{自然光 / 展馆顶灯 / 霓虹夜景 / 手机闪光灯 / 柔和商业布光 / 品牌主色}

材质细节：
{布料纹理、刺绣、金属扣、宝石、皮革、发丝、纸张、屏幕、包装材质}

文字策略：
{不需要文字 / 只要短标题 / 需要清晰短标签 / 预留文字区但不生成真实文字}

安全约束：
端庄自然，非低俗，不性感化，不暴露化，不卧室暧昧感，适合公开展示。

防串约束：
{当前角色必须保留的元素}；不要混入{不要混入的其他角色元素}。

质量约束：
写实、自然、真实服装质感，不插画风，不CG渲染，不塑料皮肤，不水印，不乱码，不错字。
```

## 2. 字段优先级

生成时优先级建议固定：

```text
主体锁定 > 防串约束 > 任务类型 > 版式构图 > 场景环境 > 光线材质 > 文字策略 > 其他风格词
```

如果出图串角色，优先改“主体锁定”和“防串约束”，不要先改光线或滤镜。

## 3. 角色防串字段

芙宁娜、茜特菈莉、多莉互相容易污染时，单独写一段：

```text
角色身份锁定为：{角色名}。
必须保留：{发型、发色、头饰、服装配色、关键道具、气质}。
禁止混入：{其他角色的发型、帽子、服装颜色、道具、表情气质}。
如果生成多格图，每一格都必须是同一个角色，只改变表情、动作、镜头或背景。
```

## 4. 文字类字段

适合海报、信息图、UI、缩略图：

```text
文字只使用少量短中文。标题不超过8个字，标签不超过4个字。
文字必须清晰可读，排版留白充足。不要乱码、错字、随机英文、真实平台logo或水印。
如果模型不擅长生成准确文字，请只预留干净标题区，不要强行生成长句。
```

## 5. 复用建议

- 写实角色照：只填主体、场景、构图、光线、材质、约束。
- 商业图：额外填主题、卖点、前中后景层次。
- 信息图/UI：额外填版式区域、短标签、图标风格。
- 多格图：必须重复角色一致性字段。
- 公开仓库预览图：必须保留非低俗、安全、无水印、无乱码字段。

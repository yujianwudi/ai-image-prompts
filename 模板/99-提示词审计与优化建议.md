# 提示词审计与优化建议

## 审计结论

这组提示词目前已经把三位角色分开了，整体可用。  
主要优化点不是再堆画质词，而是让每个角色的「发型、头饰、服装体系、气质」在提示词最前面先出现，减少模型把后面的公共模板误当成主设定。

## 已优化内容

1. **角色锚点前置**  
   每个角色的完整正向提示词开头，都先写角色名、发型、头饰、服装体系、气质。  
   这样比先写「室内漫展手机随手拍」更稳。

2. **芙宁娜污染词独立成黑名单**  
   在固定模板文件里新增了「芙宁娜污染词黑名单」。  
   茜特菈莉、多莉，以及未来其他角色都可以直接复用。

3. **补充防串矩阵**  
   把三位角色的一眼识别点和绝对不要混入的内容做成表格，方便快速检查。

4. **每个角色新增快速检查**  
   出图前只要看三四个关键点，就能判断是否已经串角色。

5. **多莉安全性强化**  
   多莉文件里明确写了「小个子成年coser」「不性感化」「不儿童化」，避免写实生图时跑偏。

## 后续还能继续优化的方向

项目里已经新增：

```text
模板/README.md
```

后续新增角色时，可以直接从这个分类模板文件夹里挑「场景 + 镜头 + 灯光 + 动作 + 负面词」进行组合，别再把所有模板塞进一个大文件。

### 1. 给每个角色做「短版提示词」

现在文件里的提示词偏详细，适合稳定还原。  
如果你要快速试图，可以再加一套短版：

```text
角色锚点 + 室内漫展手机随手拍 + 9:16 + 写实cos + 真实服装质感 + 非低俗 + 角色反向词
```

### 2. 给每个角色做「半身 / 全身 / 近景」分镜

不同景别容易影响服装识别。  
比如：

- 芙宁娜：半身更突出礼帽和表情，全身更突出蓝白贵族服。
- 茜特菈莉：全身更容易显示黑紫萨满裙和飘带。
- 多莉：半身更容易显示方形眼镜和紫金商人帽。

### 3. 增加「动作模板」

动作不要太复杂，手机随手拍更自然：

- 看向镜头，轻轻抬手打招呼。
- 站在摊位旁边，朋友突然喊她回头。
- 一只手整理帽子，另一只手拿小道具。
- 低头看周边袋，再抬头微笑。

### 4. 增加「失败修正词」

如果出图串了，不要整段重写，只要加修正：

```text
修正：发型必须保持指定角色，不改变帽子，不改变服装体系，不混入其他角色配色
```

### 5. 为新角色建立同样结构

以后新增角色建议统一用这个 md 结构：

1. 角色锁定目标  
2. 不能丢的识别点  
3. 完整正向提示词  
4. 英文辅助提示词  
5. 专属反向提示词  
6. 防串提醒  
7. 快速检查  

这样之后批量维护会舒服很多，也不容易越改越串。

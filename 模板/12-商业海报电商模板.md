# 商业海报 / 电商 / 广告模板

这些模板参考了 gpt-image-2 优秀仓库里常见的电商主图、广告创意、商品卖点图和 campaign poster 结构。  
已改写成适合本项目角色和写实 cosplay 的模板，不直接搬运原 prompt。

## 12.1 角色联名海报

```text
生成一张9:16竖版角色联名海报。主体是{角色专属提示词}，站在一个与角色气质匹配的主题场景中。画面采用商业海报构图：主体居中，前景有少量道具，中景突出服装和表情，背景有柔和氛围光和品牌感装饰。整体像高质量活动宣传图，但保持写实cosplay质感。文字区域留在画面上方或下方，但不要生成乱码。
```

## 12.2 甜品店联名视觉

```text
生成一张甜品店联名宣传视觉。主体是{角色专属提示词}，站在明亮甜品柜台前，手里自然展示一份与角色配色匹配的甜品。背景有蛋糕柜、暖色灯、玻璃反光和轻微人群虚化。画面像真实店铺联名活动海报，服装材质真实，甜品细节清楚，整体端庄自然、非低俗。
```

## 12.3 周边商品展示图

```text
生成一张角色周边商品展示图。主体是{角色专属提示词}，旁边整齐摆放徽章、亚克力立牌、明信片、小挂件和购物袋。画面采用电商主图风格，背景干净但不是纯白棚拍，桌面有真实阴影和材质。重点展示角色服装和周边质感，整体真实、清晰、可用于README预览。
```

## 12.4 九宫格广告分镜

```text
生成一张3x3九宫格广告分镜板。九个格子都是同一个角色：{角色专属提示词}。每格展示一个不同镜头：入场、回头、展示道具、近景表情、全身服装、与场景互动、细节特写、夜景氛围、结尾定格。所有格子保持同一角色的发色、头饰、服装体系和气质一致，只改变动作和镜头。整体像TVC广告分镜预览，非低俗，不乱码。
```

## 12.5 商品卖点拆解图

```text
生成一张角色服装卖点拆解图。主体是{角色专属提示词}，旁边用简洁标注展示服装亮点：头饰、发型、领结、刺绣、金属扣、宝石、手套、裙摆或裤装。版式像电商详情页，左侧角色全身图，右侧局部细节卡片。文字只用短标签，清晰可读，不要乱码。整体写实、干净、非低俗。
```

## 12.6 迷你场景商品台

```text
生成一张迷你场景广告图。把{角色专属提示词}放在一个小型主题舞台或微缩展台上，周围有与角色气质匹配的小道具、灯光、花朵、宝石、甜品或展会物料。画面像高端电商主图，主体清晰，前景和背景有层次，材质真实，不要过度卡通化。
```

## 12.7 杂志封面风角色海报

```text
生成一张竖版杂志封面风角色海报。主体是{角色专属提示词}，采用半身或三分之二身构图，背景简洁有高级感。画面需要有编辑摄影感、清晰服装纹理、自然皮肤质感和明确角色气质。可以预留封面标题位置，但不要生成乱码文字，不要水印。
```

## 12.8 活动主视觉 KV

```text

```

## 12.9 产品摄影式角色道具图

```text

```

## 12.10 品牌身份板

```text

```

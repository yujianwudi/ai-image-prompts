# gpt-image-2 提示词优化指南（联网复核 v2）

这个文件专门给 OpenAI `gpt-image-2` 用。
2026-06-10 再次联网复核后，把模板从「关键词堆叠」继续收敛成「任务模式 + 不可变主体锚点 + 可变画面参数 + 明确约束」结构。

核心目标还是你最在意的这件事：**芙宁娜、茜特菈莉、多莉不要串发型、服装和气质**。尤其是茜特菈莉、多莉，必须主动写清楚「不是芙宁娜」。

## 0. 本次联网复核结论

本次主要参考 OpenAI 官方图片生成文档、`gpt-image-2` 模型页和 OpenAI Cookbook 图片提示词指南，只提炼规则，不复制外部长提示词。

- `gpt-image-2` 是图片生成模型，可用于生成和编辑；官方说明它支持更灵活的图片尺寸、自定义输出质量和输出格式。
  参考：<https://developers.openai.com/api/docs/models/gpt-image-2>
- 图片生成文档确认：生成时应围绕 `prompt` 清楚说明目标，并可按需要设置 `size`、`quality`、`output_format` 等输出选项。
  参考：<https://platform.openai.com/docs/guides/image-generation>
- Cookbook 提示词指南强调：先明确输出用途，再稳定描述图像类型、主体、场景、相机/构图、光线、材质、文字和限制；复杂任务用分段标签比散乱关键词更稳。
  参考：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>
- 对写实照片，不要只写 `masterpiece, best quality, 8k`。要直接写「写实手机照片、普通观众视角、真实光线、真实材质、不过度磨皮」。
- 对角色防串，负面词要变成可执行的自然约束：例如「这个角色不是芙宁娜，不要白蓝短发，不要蓝黑礼帽，不要枫丹蓝白歌剧服」。
- 对带文字的图，只给短标题和短标签；如果不需要文字，要明确写「不需要画面文字，不要水印、logo、乱码或随机英文」。
- 对编辑图，最稳的是拆成「保留 / 修改 / 不要修改」三块，不要只写一句「帮我改一下」。

## 1. 本仓库提示词优先级

角色 cosplay 图最容易被强势角色元素污染，所以本仓库固定按这个顺序写：

1. **任务模式**：写实手机照片、README 预览图、角色卡、商业海报、封面等，只选一个。
2. **不可变主体锚点**：角色名、发型、发色、头饰、服装体系、关键道具、气质。
3. **必须保留**：把最不能错的 3-6 个识别点列出来。
4. **可变场景**：室内漫展、甜品店、夜景街拍、展馆走廊等。
5. **镜头构图**：9:16 竖图、半身/三分之二身/全身、普通观众手机视角。
6. **光线材质**：真实环境光、脸部自然曝光、布料、刺绣、金属、宝石、发丝。
7. **文字策略**：无文字，或只允许短标题/短标签。
8. **安全与防串约束**：非低俗、不性感化、不儿童化、不混入其他角色元素。

> 角色图里，「主体锁定」要比「漂亮、高清、氛围感」更靠前。否则模型容易先学到芙宁娜的舞台女王气质，再把别的角色带偏。

## 5. 9:16 尺寸和 API 参数

如果工具允许自定义尺寸，严格 9:16 竖图优先用接近 9:16 且边长为 16 的倍数的尺寸：

```text
model: gpt-image-2
size: 1024x1824       # 接近 9:16，适合竖版手机人像
quality: low          # 草稿，先看构图和防串
quality: medium       # README 预览图、常规角色图
quality: high         # 角色卡、海报、信息图等细节密集图
output_format: jpeg   # 写实照片预览常用；需要无损再用 png
background: opaque    # 写实漫展/街拍通常用不透明背景
```

补充：

- `1024x1536` 是 2:3 竖图，不是严格 9:16；如果平台只给固定档位，可以使用它，但提示词里仍写「9:16 竖图构图」。
- 更大竖图可用 `1088x1936` 一类接近 9:16 的尺寸，但先用低/中质量确认角色不串，再提高质量。
- 不要把 Midjourney 的 `--ar`、`--style raw`、`--stylize` 写进 OpenAI API 参数。
- 透明背景、输入保真度等能力要以当前 API 校验为准；模板层面不要靠一句「透明背景」硬赌。

## 6. 负面词不要堆太散

### 不推荐

```text

```

### 推荐

```text
不要生成低俗或性感化姿势。不要让服装暴露化、泳装化、内衣化或透视化。不要把角色画成二次元插画、CG 渲染、塑料皮肤或过度磨皮的棚拍大片。不要混入其他角色的发型、帽子、服装配色、道具和表情气质。
```

角色防串时，把污染源写具体：

```text
这个角色不是芙宁娜，不要白蓝短发，不要蓝黑礼帽，不要枫丹蓝白歌剧服，不要水神舞台女王气质。
```

## 7. 带文字图片写法

适合海报、信息图、UI、封面缩略图。`gpt-image-2` 对文字更强，但提示词仍然要短、准、少。

```text
文字策略：
只允许出现短中文标题“角色防串”。标题放在左上角，字数少，清晰可读。不要生成长段文字，不要乱码，不要随机英文，不要水印，不要真实平台 logo。
```

如果文字不是重点，直接写：

```text
不需要画面文字；如果模型生成文字，也只能是不可抢主体的简短装饰，不要乱码、水印或真实品牌 logo。
```

## 8. 图像编辑提示词

编辑图片时，最稳的是分清「保留 / 修改 / 不要修改」：

```text
请基于输入图片进行编辑。

保留：
保留人物身份、脸部特征、发型、头饰、服装配色、关键配件、姿势、镜头角度和写实手机照片质感。

修改：
只把背景改成{新场景}，并让光线、反光、阴影和氛围自然匹配新场景。

不要修改：
不要改变角色身份，不要换发型，不要换服装，不要改变头饰、配件和角色气质，不要低俗化，不要生成乱码文字。
```

修正串角色时：

```text
当前问题：图片混入了{错误角色元素}。
请只修正：{发型 / 头饰 / 服装配色 / 道具 / 气质}。
必须保留：原图构图、场景、光线、照片质感、姿势和表情强度。
不要修改：不要换角色，不要换背景，不要低俗化，不要添加水印或乱码文字。
```

## 9. 出图后迭代公式

```text
这张图的问题是：{具体问题，例如混入芙宁娜礼帽 / 服装太像插画 / 背景太棚拍}
请保留：{已经正确的角色、构图、姿势、光线}
请修正：{只修正错误发型、帽子、服装配色、材质或背景}
不要改变：{不要换角色、不要换服装体系、不要低俗化、不要加水印乱码}
```

优先级：

1. 先修正角色锚点。
2. 再修正构图和场景。
3. 再补光线材质。
4. 最后才提高质量档位或加细节词。

## 10. 最重要的原则

1. **先写清楚任务模式**：写实照片、README 预览、角色卡、海报、信息图不要混用。
2. **角色防串先锁主体**：发型、头饰、服装体系、配件、气质放在前面。
3. **9:16 不等于 1024x1536**：严格竖版手机构图优先用 `1024x1824` 这类接近 9:16 的尺寸。
4. **场景要像真实拍摄**：谁在拍、在哪里拍、背景有什么、光线怎样。
5. **材质写具体**：布料、刺绣、金属、宝石、皮革、发丝比空泛画质词更有效。
6. **约束写成自然句**：不要只堆 negative prompt。
7. **文字越短越稳**：标题和标签可以，长正文不要交给生图模型。
8. **一次只选一个输出类型**：不要把写实照片、商业海报、UI 截图和分镜板塞进同一条提示词。

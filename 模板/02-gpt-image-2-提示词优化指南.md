# gpt-image-2 提示词优化指南

这个文件专门给 OpenAI `gpt-image-2` 用。  
它更适合读「清楚的自然语言任务说明」，不要只塞一长串逗号关键词。

## 1. 推荐结构

把提示词写成分段说明，模型更容易抓重点：

```text
目标：
生成一张写实真人cosplay照片，用于展示角色提示词模板效果。

主体：
角色是谁，发型、头饰、服装体系、关键配件、气质是什么。

场景：
地点在哪里，例如室内漫展、甜品店、城市夜景、展馆走廊。

构图：
9:16竖图，半身/全身/三分之二身，手机随手拍，观众视角。

光线：
展馆顶灯、窗边自然光、夜景霓虹、手机闪光灯等。

材质：
布料纹理、刺绣、金属扣、宝石、发丝、皮革等真实质感。

约束：
非低俗，不性感化，不插画风，不CG风，不混入其他角色发型、服装和气质。
```

## 2. gpt-image-2 更推荐的写法

### 推荐

```text
生成一张9:16竖图写实手机照片。画面像朋友在室内漫展通道随手拍下的cosplay照片。
主体是一位芙宁娜coser：白色短发带浅蓝挑染，戴蓝黑小礼帽，穿枫丹蓝白贵族歌剧风服装，表情自信、俏皮、稍微戏剧化。
背景有人群、展位灯牌和海报墙，但背景轻微虚化。服装需要有真实布料、刺绣、金属扣和宝石质感。
保持端庄、非低俗，不要性感化，不要插画风，不要CG渲染，不要混入茜特菈莉或多莉的发型和服装。
```

### 不推荐

```text
masterpiece, best quality, 8k, ultra detailed, Furina, cosplay, convention, realistic, blue, white, dress, beautiful, negative: bad hands, bad face...
```

这种关键词堆叠对 gpt-image-2 不如清楚的自然语言稳定。

## 3. 固定模板改写方式

原本的模板可以继续用，但建议改成「句子 + 约束」：

### 原关键词式

```text
室内漫展手机随手拍，9:16竖图，写实摄影风格，真实服装材质，非低俗
```

### gpt-image-2 自然语言式

```text
生成一张9:16竖图的写实手机照片。画面像普通观众在室内漫展现场随手拍摄，背景有人群、展位、海报和灯牌，但保持轻微虚化。角色服装需要有真实布料纹理、缝线、刺绣、金属扣和宝石质感。整体端庄自然，非低俗，不性感化。
```

## 4. 负面词写法

gpt-image-2 不建议只写一堆「负面关键词」。  
更稳的方式是写成明确约束：

```text
不要生成低俗或性感化姿势。不要让服装暴露化、泳装化或内衣化。不要把角色画成二次元插画、CG渲染或塑料皮肤。不要混入其他角色的发型、帽子、服装配色和气质。
```

角色防串时，也用自然句：

```text
这个角色不是芙宁娜，不要白蓝短发，不要蓝黑礼帽，不要枫丹蓝白歌剧服，不要水神舞台女王气质。
```

## 6. 写实 cosplay 专用模板

```text
生成一张写实真人cosplay照片，9:16竖图。照片像朋友用手机在真实环境里随手拍摄，不是棚拍，不是商业大片。
角色需要保持明确的cosplay服装结构，布料、刺绣、金属扣、宝石、皮革和发丝都有真实质感。背景保留轻微现场杂乱感，例如人群、展位、灯牌、海报、桌椅或城市街景，但不要抢主体。
整体端庄、自然、非低俗，不要性感化，不要过度磨皮，不要二次元插画风，不要CG渲染。
```

## 7. 角色防串专用模板

```text
请严格保持当前角色设定。发型、发色、头饰、服装体系、配件和气质都必须属于当前角色。
不要混入其他角色的标志元素。不要把角色的发型长度、帽子、衣服配色、道具或表情气质替换成其他角色。
如果角色是茜特菈莉或多莉，不要出现芙宁娜的白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服和水神舞台女王气质。
```

## 8. API 参数建议

如果你用 OpenAI Images API，可以优先这样想：

```text
model: gpt-image-2
size: 1024x1536 或其他竖图尺寸
quality: medium 或 high
output_format: jpeg / png / webp
```

如果你的工具不让设置尺寸参数，就在提示词里明确写：

```text
9:16竖图，vertical portrait composition
```

## 9. 最重要的原则

1. **少堆关键词，多写清楚句子。**
2. **先讲主体，再讲场景。**
3. **把角色识别点放在前面。**
4. **把“不要什么”写成自然约束。**
5. **不要一次性塞太多互相冲突的模板。**

## 10. 按输出类型选择文件

```text
写实照片：10 / 11 / 20 / 30 / 40 / 60
商业海报、电商主图：12 / 40 / 60
信息图、UI、社媒截图：13 / 60 / 70
角色卡、分镜、九宫格：14 / 60
优秀仓库提炼总结：03
```

如果不知道选哪种，先从「写实照片」开始，不要一次性混用商业海报、UI截图、信息图和分镜板。

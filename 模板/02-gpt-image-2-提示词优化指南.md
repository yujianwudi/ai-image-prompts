# gpt-image-2 提示词优化指南（联网复核版）

这个文件专门给 OpenAI `gpt-image-2` 用。  
2026-06-10 联网复核后，模板改成更清楚的「任务说明 + 主体锁定 + 场景 + 关键细节 + 约束」结构，避免只靠一串关键词赌概率。

## 0. 联网复核结论

本次只把外部资料提炼成结构规则，没有复制网上长提示词。

- OpenAI 图片生成文档确认 `gpt-image-2` 可用于生成、编辑和输出自定义图像，提示词应围绕 `prompt` 清楚说明生成目标。  
  参考：<https://platform.openai.com/docs/guides/image-generation>
- OpenAI Cookbook 的图片提示词指南强调：先明确输出用途，再用稳定顺序描述场景、主体、关键细节和约束；复杂任务用分段或标签更稳。  
  参考：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>
- 对写实图，提示词里要直接说明「真实照片 / 手机照片 / 自然光 / 材质细节」，不要只写 `masterpiece, best quality, 8k`。
- 对角色防串，负面词要写成自然约束，例如「不要混入芙宁娜的白蓝短发、蓝黑礼帽和枫丹歌剧服」。
- 对带文字的海报、信息图、UI，文字越短越好；如果必须出现文字，要用引号明确写出短标题，并要求清晰可读、不要乱码。

## 1. 本仓库推荐结构

角色 cosplay 场景最容易串角色，所以本仓库采用「主体锁定优先」：

```text
输出用途：
生成一张可公开展示的写实真人 cosplay 图，9:16 竖图。

主体锁定：
{角色是谁、发型、发色、头饰、服装体系、关键配件、气质}

必须保留：
- {角色识别点1}
- {角色识别点2}
- {角色识别点3}

场景环境：
{室内漫展/甜品店/夜景街拍/展馆走廊等，背景有什么}

构图镜头：
{普通观众视角、手机随手拍、半身/三分之二身/全身、9:16竖图}

光线色彩：
{展馆顶灯、窗边自然光、霓虹、暖光，脸部曝光自然，服装颜色不跑偏}

材质细节：
{布料纹理、缝线、刺绣、金属扣、宝石、皮革、发丝、道具材质}

文字策略：
{不需要文字 / 只出现短中文标题“xxx” / 不要水印、logo、乱码}

安全与防串约束：
端庄自然，非低俗，不性感化，不暴露化，不卧室暧昧感。
不要插画风，不要CG渲染，不要塑料皮肤。
不要混入{其他角色的发型、帽子、服装配色、道具和气质}。
```

> 如果不是角色防串任务，可以按「场景 → 主体 → 关键细节 → 约束」写；但本仓库三位角色最怕混到芙宁娜，所以先锁主体更安全。

## 2. 固定基底改写方式

### 旧关键词式

```text
室内漫展手机随手拍，9:16竖图，写实摄影风格，真实服装材质，非低俗
```

### gpt-image-2 分段式

```text
输出用途：
生成一张9:16竖图的写实真人 cosplay 手机照片，用于公开展示提示词效果。

场景环境：
画面像普通观众在室内漫展现场随手拍摄。背景有人群、展位、海报墙和灯牌，但背景轻微虚化，不抢主体。

构图镜头：
手机手持抓拍感，普通观众视角，主体半身或三分之二身清晰，不要棚拍大片感。

光线材质：
室内展馆自然顶灯，脸部曝光自然。服装需要真实布料纹理、缝线、刺绣、金属扣、宝石、腰饰和发丝质感。

约束：
整体端庄自然，非低俗，不性感化，不刻意暴露，不插画风，不CG渲染，不过度磨皮，不塑料皮肤。
```

## 3. 写实 cosplay 一键母版

```text
生成一张9:16竖图写实手机照片，用于公开展示角色 cosplay 提示词效果。

主体锁定：
{角色专属提示词}

场景环境：
角色站在室内漫展通道或展位旁，背景有人群、海报墙、摊位灯牌和轻微玻璃反光。背景有真实现场感，但轻微虚化，不抢主体。

构图镜头：
普通观众视角，手持手机随手拍，主体半身或三分之二身清晰，画面有轻微生活感，不像专业棚拍。

光线色彩：
室内展馆自然顶灯，脸部曝光自然，眼睛有轻微高光，服装颜色准确不跑偏。

材质细节：
真实服装质感，布料褶皱、缝线、刺绣、金属扣、宝石、皮革、蝴蝶结、腰饰、发丝和手部道具都要像真实可穿戴 cosplay 服。

文字策略：
不需要画面文字，不要水印、logo、乱码或随机英文。

安全与防串约束：
端庄自然，非低俗，不性感化，不暴露化，不泳装化，不内衣化，不卧室暧昧感。
不要二次元插画风，不要CG渲染，不要塑料皮肤，不要过度磨皮。
角色发型、头饰、服装体系、关键配件和气质必须准确，不要混入其他角色设定。
```

## 5. 负面词不要堆太散

### 不推荐

```text
bad hands, low quality, worst quality, nsfw, sexy, bikini, anime, cgi, wrong hair, wrong hat, wrong outfit
```

### 推荐

```text
不要生成低俗或性感化姿势。不要让服装暴露化、泳装化、内衣化或透视化。不要把角色画成二次元插画、CG渲染、塑料皮肤或过度磨皮的棚拍大片。不要混入其他角色的发型、帽子、服装配色、道具和表情气质。
```

角色防串时，把污染源写具体：

```text
这个角色不是芙宁娜，不要白蓝短发，不要蓝黑礼帽，不要枫丹蓝白歌剧服，不要水神舞台女王气质。
```

## 6. 带文字图片写法

适合海报、信息图、UI、封面缩略图。

```text
文字策略：
只允许出现短中文标题“角色防串”。标题放在左上角，字数少，清晰可读。不要生成长段文字，不要乱码，不要随机英文，不要水印，不要真实平台 logo。
```

如果文字不是重点，直接写：

```text
不需要画面文字；如果模型生成文字，也只能是不可抢主体的简短装饰，不要乱码、水印或真实品牌 logo。
```

## 7. 图像编辑提示词

编辑图片时，最稳的是分清「保留 / 修改 / 不要改」：

```text
请基于输入图片进行编辑。

保留：
保留人物身份、脸部特征、发型、头饰、服装配色、关键配件、姿势、镜头角度和写实手机照片质感。

修改：
只把背景改成{新场景}，并让光线、反光和氛围自然匹配新场景。

不要修改：
不要改变角色身份，不要换发型，不要换服装，不要改变头饰、配件和角色气质，不要低俗化，不要生成乱码文字。
```

## 8. API 参数建议

```text
model: gpt-image-2
size: 1024x1536      # 适合 9:16 竖图人像
quality: low         # 草稿、快速试结构
quality: medium      # README 预览图、常规出图
quality: high        # 角色卡、海报、信息图等细节密集图
output_format: jpeg  # 照片预览常用；需要无损再用 png
```

注意：

- 不要把 Midjourney 的 `--ar`、`--style raw`、`--stylize` 写进 OpenAI API 参数。
- 如果当前工具不开放 `size`，就在提示词里明确写「9:16竖图，vertical portrait composition」。
- 如果要透明背景，先查当前模型和工具是否支持；不要只靠提示词硬写透明。

## 9. 出图后迭代公式

```text
这张图的问题是：{具体问题，例如混入芙宁娜礼帽 / 服装太像插画 / 背景太棚拍}
请保留：{已经正确的角色、构图、姿势、光线}
请修正：{只修正错误发型、帽子、服装配色、材质或背景}
不要改变：{不要换角色、不要换服装体系、不要低俗化、不要加水印乱码}
```

## 10. 最重要的原则

1. **先写清楚输出用途**：写实照片、README预览、角色卡、海报、信息图不要混用。  
2. **角色防串先锁主体**：发型、头饰、服装体系、配件、气质放在前面。  
3. **场景要像真实拍摄**：谁在拍、在哪里拍、背景有什么、光线怎样。  
4. **材质写具体**：布料、刺绣、金属、宝石、皮革、发丝比空泛画质词更有效。  
5. **约束写成自然句**：不要只堆负面关键词。  
6. **文字越短越稳**：标题和标签可以，长正文不要交给生图模型。  
7. **一次只选一个输出类型**：不要把写实照片、商业海报、UI截图和分镜板塞进同一条提示词。

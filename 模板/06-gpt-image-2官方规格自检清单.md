# gpt-image-2 官方规格自检清单

这个文件专门给复制提示词前做最后一遍检查用。
它补在 `02-gpt-image-2-提示词优化指南.md` 和 `04-gpt-image-2一键实战模板.md` 后面，目标是避免两类问题：

1. 提示词结构又退回「关键词堆叠」。
2. OpenAI `gpt-image-2` 的尺寸、格式、编辑参数和 Midjourney 参数混写。

参考来源只按 OpenAI 官方资料复核：

- OpenAI 图片生成文档：<https://platform.openai.com/docs/guides/image-generation>
- OpenAI `gpt-image-2` 模型页：<https://developers.openai.com/api/docs/models/gpt-image-2>
- OpenAI Cookbook 图片提示词指南：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>

## 1. API 参数先过这一关

写实 cosplay、室内漫展、手机竖图默认用这一组：

```text
model: gpt-image-2
size: 1024x1824
quality: medium
output_format: jpeg
output_compression: 85
background: opaque
```

自检：

- `size` 不写 `--ar 9:16`，那是 Midjourney 参数，不是 OpenAI API 参数。
- 严格手机竖屏优先 `1024x1824`；`1024x1536` 是 2:3 备选，不要标成严格 9:16。
- 写实 README 预览图优先 `jpeg` 或 `webp`；需要无损细节再用 `png`。
- `background: opaque` 更适合真实漫展、街拍、室内场景。
- `gpt-image-2` 不要依赖透明背景或 `input_fidelity` 这类不稳定/不适用字段；编辑图靠提示词明确「保留 / 修改 / 不要修改」。

## 2. 本仓库推荐尺寸档位

这些档位都按本仓库工具 `python 工具/validate_gpt_image2_parameters.py --check` 校验：

| 档位 | size | quality | 用途 |
| --- | --- | --- | --- |
| 草稿手机图 | `640x1136` | `low` | 先看角色锚点、防串和构图，别一开始就高成本 |
| 快速 9:16 | `720x1280` | `low` | 严格 9:16，适合快速试画面方向 |
| 常规预览 | `864x1536` | `medium` | 公开预览、角色图、README 样张 |
| 仓库默认 | `1024x1824` | `medium` | 写实漫展手机随手拍主力档 |
| 细节预览 | `1088x1936` | `high` | 角色卡、封面、海报前的细节版 |
| 高细节交付 | `1440x2560` | `high` | 已确认不串角色后再用 |
| 最大实验 | `2160x3840` | `high` | 最后放大用，成本高，不适合第一轮试错 |

如果你想临时检查一个尺寸：

```powershell
python 工具/validate_gpt_image2_parameters.py --size 1024x1824 --require-9-16
python 工具/validate_gpt_image2_parameters.py --size 1024x1536 --require-9-16
```

第二条会提醒：它是 API 可用的竖图，但不是严格 9:16。

## 3. gpt-image-2 提示词顺序

本仓库继续固定这个顺序：

```text
任务模式：
不可变主体锚点：
必须保留：
场景环境：
镜头构图：
光线色彩：
材质细节：
文字策略：
安全与防串约束：
出图自检：
```

不要写成这样：

```text
masterpiece, best quality, 8k, beautiful cosplay, anime, cinematic, perfect face
```

更稳的写法是：

```text
任务模式：生成一张可公开展示的 9:16 竖图写实手机照片。
不可变主体锚点：先写角色发型、头饰、服装体系、关键道具和气质。
场景环境：写清楚谁在拍、在哪里拍、背景有什么、背景是否虚化。
材质细节：写真实布料、缝线、刺绣、金属扣、宝石、发丝和道具质感。
安全与防串约束：非低俗、不性感化、不儿童化，不混入其他角色元素。
```

## 4. 三角色防串最后检查

- 蓝黑小礼帽。
- 枫丹蓝白歌剧服。
- 水滴宝石、金色纹扣。
- 自信俏皮、优雅戏剧化，但不要过度舞台大片化。

- 茜特菈莉的淡粉紫长发、前侧细辫、黑紫纳塔萨满服。
- 多莉的方形眼镜、紫金商人帽、金币钱袋、小灯壶。

## 5. 带文字图片只写短文本

适合海报、信息图、封面时这样写：

```text
文字策略：只允许一个短中文标题「角色防串清单」和 3 个短标签。文字清晰可读，放在留白区域。
不要长段落，不要乱码，不要随机英文，不要真实平台 logo，不要水印。
```

如果文字不是重点，直接写：

```text
不需要画面文字；不要水印、logo、乱码或随机英文。
```

## 6. 编辑图必须拆成三段

如果上一张图串到芙宁娜，不要只写「改一下」。
用这个结构：

```text
保留：原图构图、场景、光线、手机照片质感、姿势和表情强度。
修改：只修正角色发型、头饰、服装配色、关键配件和气质，让它回到正确角色。
不要修改：不要换角色身份，不要换背景，不要改变镜头角度，不要低俗化，不要生成乱码文字。
```

## 7. 复制前 10 秒自检

- 是否只选了一个输出类型：写实照片 / 角色卡 / 海报 / 信息图 / 编辑修正？
- 主体锚点是否放在场景和画质词前面？
- 茜特菈莉、多莉是否明确写了「不是芙宁娜」？
- 多莉是否明确成年化表达？
- 是否写了真实服装材质，而不是只写高质量？
- 是否把 `1024x1536` 当成 2:3 备选，而不是严格 9:16？
- 是否没有把 `--ar`、`--style raw`、`--stylize` 写进 OpenAI API 参数？
- 是否没有要求真实品牌 logo、真实平台水印或长段小字？

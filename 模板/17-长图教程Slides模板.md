# 长图教程 / Slides 模板

适合做教程长图、步骤说明、PPT封面与页面。  
重点是版式清楚、短句可读、图文区域分明，不要让模型生成一大段容易乱码的文字。

## 1. 9:16教程长图

```text
生成一张9:16竖版教程长图。

主题：
{教程主题，例如“如何稳定生成茜特菈莉写实cos图”}

版式：
从上到下分成5个步骤卡片：角色锚点、场景选择、镜头构图、光线材质、安全约束。每个卡片有一个小图标、一句短标题和一行很短的说明。

视觉：
干净现代，留白充足，卡片边缘清晰，背景轻微渐变或浅色纸张质感。

文字：
只使用短中文标题和短标签，文字必须清晰可读，不要乱码，不要长段落，不要随机英文。

约束：
如果出现角色小图，必须保持同一个角色设定，不混入其他角色发型、帽子、服装配色或气质。
```

## 2. PPT封面页

```text
生成一张16:9 PPT封面页。

标题主题：
{主题}

版式：
左侧为标题与副标题区域，右侧为主视觉图。标题区留白大，层级明确；主视觉可以是{角色专属提示词}或模板卡片组合。

风格：
专业、干净、现代，适合演示文稿，不要过度花哨。

文字：
只放短标题和短副标题，文字清晰，不要乱码，不要真实公司logo。
```

## 3. PPT内容页

```text
生成一张16:9 PPT内容页。

主题：
{页面主题}

版式：
三栏卡片布局，每栏包含一个短标题、一个图标和一张小示意图。页面底部有简单页脚装饰，但不要真实品牌logo。

内容方向：
1. 主体锁定
2. 场景构图
3. 约束修正

文字：
每栏只使用短中文标题，尽量少字，清晰可读，不要乱码和错字。
```

## 4. 多页统一风格规则

```text
如果生成一组 Slides，所有页面保持同一套配色、字体风格、图标风格、页边距和卡片圆角。角色出现时保持同一发型、头饰、服装配色和气质，只改变姿势或页面位置。
```

## 5. 避坑

- 不要让模型写完整教程正文，容易乱码。
- 长图优先“短标题 + 图标 + 留白”。
- Slides 优先固定网格、边距、卡片结构。
- 有角色时，把角色一致性约束重复写进每页任务。

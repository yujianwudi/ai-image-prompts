# AI生图模板文件夹索引

这里是拆分后的模板文件夹，不再把所有内容塞在一个大文件里。  
建议每次只打开需要的分类，避免把场景、镜头、灯光、负面词混在一起。

## 推荐使用顺序

1. 先打开角色文件夹，复制角色专属提示词：
   - `../角色/01-芙宁娜-提示词.md`
   - `../角色/02-茜特菈莉-提示词.md`
   - `../角色/03-朵莉亚-多莉Dori-提示词.md`
2. 再从下面分类里各挑一小段：
   - 场景：选 1 个
   - 镜头：选 1 个
   - 灯光：选 1 个
   - 材质：选 1 个
   - 动作：按需要选 0-1 个
   - 负面词：选通用负面 + 对应角色污染负面
3. 最后按平台加参数。OpenAI `gpt-image-2` 优先用自然语言分段提示词；Midjourney 再用 `--ar 9:16 --style raw --stylize 50`。

## 最不容易串的组合

```text
角色专属提示词 + 场景模板 + 镜头模板 + 灯光模板 + 真实材质模板 + 通用安全负面词 + 对应污染负面词 + 平台参数
```

## 注意

不要一次性复制整个模板文件夹。  
一次生成只需要 4-6 段模板，太多反而容易互相污染。

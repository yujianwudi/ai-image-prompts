# 角色卡 / 分镜 / 设定集模板

这些模板参考了优秀 gpt-image-2 仓库里的角色参考卡、角色介绍页、分镜板、九宫格、卡牌合集等结构。  
重点用于解决角色一致性和多图展示问题。

## 14.1 角色参考卡

```text
生成一张角色参考卡。主体是{角色专属提示词}。版式包含：正面半身图、全身站姿、小道具特写、发型头饰特写、服装材质特写、气质关键词。所有区域保持同一个角色设定，不改变发色、发型、头饰、服装体系和配色。文字只用短中文标签，清晰可读，不要乱码。
```

## 14.2 三视图设定表

```text
生成一张角色三视图设定表。展示同一角色的正面、侧面、背面站姿，保持完全一致的发型、头饰、服装配色、配件和体型比例。背景简洁，像角色设计设定稿，但材质仍然保留写实cosplay质感。不要改变角色身份，不要混入其他角色元素。
```

## 14.3 表情九宫格

```text
生成一张3x3表情九宫格。九个格子都是同一个角色：{角色专属提示词}。每格只改变表情：自然微笑、惊讶、害羞、冷淡、认真、俏皮、困惑、开心、安静。发型、头饰、服装和配色必须完全一致。画面干净，不低俗，不乱码。
```

## 14.4 动作九宫格

```text
生成一张3x3动作九宫格。九个格子都是同一个角色：{角色专属提示词}。每格只改变动作：回头、整理头饰、拿道具、打招呼、看向摊位、走路抓拍、展示服装、坐在休息区、夜景跟拍。角色设定保持一致，不混入其他角色发型或服装。
```

## 14.5 服装拆解设定页

```text
生成一张服装拆解设定页。主体是{角色专属提示词}，旁边展示头饰、领口、袖口、腰饰、下装、鞋子、道具、材质样本。每个局部都要和角色主图一致。版式像设计说明页，短标签清晰，不要乱码，不要多余logo。
```

## 14.6 角色卡牌

```text
生成一张收藏卡牌风角色图。主体是{角色专属提示词}，居中站立或半身构图，边框使用与角色配色一致的装饰纹样。卡牌下方有短标题和几个属性标签，但不要乱码。整体像精致收藏卡，不要过度游戏UI化，不要低俗。
```

## 14.7 漫展一天分镜

```text
生成一张六格分镜板，主题是角色在漫展的一天。六格分别是：入场、展位前拍照、甜品店休息、与朋友互动、夜景街拍、结束回头。每格都是同一个角色：{角色专属提示词}。只改变场景和动作，不改变发型、头饰、服装和气质。
```

## 14.8 广告TVC分镜

```text
生成一张9格TVC广告分镜板。主体是{角色专属提示词}，故事是角色从漫展走到甜品店再到城市夜景。每格有电影镜头感：建立镜头、中景、特写、道具、转场、情绪、全身、背影、结尾定格。角色一致性必须稳定，不要串角色。
```

## 14.9 角色杂志内页

```text
生成一张角色杂志内页。左侧是角色大图，右侧是三张小图：服装细节、表情特写、场景互动。整体像时尚杂志排版，留白干净，标题区域不要乱码。角色服装材质真实，发型和头饰准确。
```

## 14.10 Prompt实验记录板

```text
生成一张Prompt实验记录板。画面展示同一角色在三种模板下的效果：室内漫展、甜品店联名、城市夜景。每个小图下方有短标签和简短参数区。角色必须一致，版式整齐，文字清晰，不要乱码。适合放在README说明模板效果。
```

# 8. 平台参数模板

## 8.1 OpenAI gpt-image-2 写实竖图

```text
model: gpt-image-2
size: 1024x1536
quality: medium 或 high
output_format: jpeg
```

适合：README预览图、写实cos、竖图人像、漫展手机随手拍。  
如果想保留透明背景或精细后期，要先确认当前工具是否开放对应参数；不要只靠提示词硬写。

### 尺寸建议

```text
常用竖图：1024x1536
常用横图：1536x1024
常用方图：1024x1024
自定义尺寸：尽量保持宽高为16的倍数，并控制在工具允许范围内
```

### 输出格式建议

```text
README预览图：jpeg 或 webp
需要透明或无损：png
需要控制体积：jpeg/webp + output_compression
```

### 注意

```text
GPT图片模型通常返回base64图像数据。不要把Midjourney的参数写进OpenAI API参数里；Midjourney的 --ar、--style raw、--stylize 只给Midjourney用。
```

## 8.2 OpenAI gpt-image-2 提示词写法

```text
用自然语言分段描述：目标、主体、场景、构图、光线、材质、约束。
```

示例：

```text
生成一张9:16竖图写实手机照片。主体是一位角色coser，站在室内漫展展位旁。画面像朋友随手拍摄，背景有人群和灯牌但轻微虚化。服装需要真实布料、刺绣、金属扣和宝石质感。整体端庄自然，非低俗，不性感化，不插画风，不CG渲染。
```

## 8.3 OpenAI gpt-image-2 图像编辑

```text
model: gpt-image-2
image: 输入参考图
prompt: 明确写保留什么、修改什么、不要修改什么
```

编辑类提示词要特别写清楚：

```text
保留人物身份、脸部特征、发型、服装和配件；只修改背景/光线/局部错误；不要改变角色身份。
```

## 8.4 Midjourney 竖图写实

```text
--ar 9:16 --style raw --stylize 50
```

适合：想要更听提示词、更少自动艺术化。  
如果画面太普通，可以把 `--stylize 50` 改到 `--stylize 100` 或 `--stylize 150`。

## 8.5 Midjourney 半身头像

```text
--ar 3:4 --style raw --stylize 75
```

适合：头像、半身、重点看发型和头饰。

## 8.6 Midjourney 全身图

```text
--ar 9:16 --style raw --stylize 50
```

并在正向词里加：

```text
full body, head to toe visible, shoes visible, complete outfit
```

## 8.7 SDXL / WebUI 通用比例

```text
832x1216 或 768x1344，竖图，CFG 5-7，采样步数 25-35
```

适合：写实角色cos图。  
如果脸太AI，降低过度画质词，增加「手机随手拍、真实皮肤纹理、不过度磨皮」。

## 8.8 Flux / 自然语言模型

```text
用完整自然句描述，不要只堆关键词。重点写清楚：角色是谁、站在哪里、谁在拍、光线怎样、服装材质怎样、不要什么。
```

Flux一类模型通常更适合自然语言描述，所以可以少用括号权重，多用清楚句子。

# 质量评估与迭代流程模板

这个模板用于把「出图 → 评分 → 修正 → 再生成」标准化。  
详细记录文件在 `../评估/` 文件夹。

## 15.1 出图后先问五个问题

```text
1. 这个角色有没有串到其他角色？
2. 发型、头饰、服装体系是否准确？
3. 画面是否适合公开展示，是否端庄、非低俗？
4. 构图是否符合目标，比如9:16、半身、全身、九宫格？
5. 如果有文字，是否清晰可读；如果不需要文字，是否没有乱码？
```

## 15.2 重新生成模板

```text
上一张图的问题是：{问题描述}

请重新生成一张图，保持原目标：
{原始目标}

重点修正：
{修正要求}

不要改变：
{需要保留的角色/构图/场景/光线}

约束：
端庄自然，非低俗，不性感化，不插画风，不乱码，不串角色。
```

## 15.3 图像编辑模板

```text
请基于输入图片进行局部修正。

保留：
保留原图构图、光线、场景、人物姿势和照片质感。

修改：
只修改{需要修正的部分}。

具体要求：
{正确角色发型/头饰/服装/道具/文字}

不要修改：
不要改变角色身份，不要换场景，不要改变镜头角度，不要低俗化。
```

## 15.4 失败类型决策

| 失败类型 | 建议操作 |
| --- | --- |
| 构图完全错 | 重新生成 |
| 角色大面积串掉 | 重新生成 |
| 只有发型/头饰局部错 | 图像编辑 |
| 背景很好但服装错 | 图像编辑 |
| 多格图每格角色不一致 | 重新生成并强化一致性 |
| 文字乱码 | 如果文字重要则重新生成；不重要则要求无文字 |
| 擦边或低俗 | 重新生成并加强公开展示约束 |

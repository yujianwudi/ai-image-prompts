# 4. 灯光 / 色彩固定模板

## 4.1 展馆冷白顶灯

```text
室内展馆冷白顶灯，光线均匀但不完美，脸部有真实轻微阴影，服装颜色准确，背景灯牌轻微发光，手机摄影真实感
```

## 4.2 窗边自然侧光

```text
窗边自然侧光，光线从一侧照亮脸部和发丝，另一侧有柔和阴影，画面清透，服装纹理和金属配件有自然高光，写实摄影
```

## 4.3 夜景霓虹光

```text
城市夜景霓虹光，背景有蓝紫色和暖黄色灯光虚化，角色脸部保持自然肤色，服装边缘有轻微彩色反光，真实夜拍噪点，电影感但不过度
```

## 4.4 手机闪光灯

```text
手机闪光灯抓拍，角色正面被轻微闪光照亮，背景稍暗，皮肤和布料有真实直接光反射，像朋友晚上随手打开闪光灯拍摄，不要棚拍精修感
```

## 4.5 暖色商场灯

```text
暖色商场灯光，背景有金色灯带和橱窗反光，角色服装颜色保持准确，整体温暖生活感，真实室内照片质感
```

## 4.6 阴天柔光

```text
阴天户外柔光，没有强烈阴影，脸部光线柔和，服装纹理清晰，背景城市或公园环境自然虚化，颜色偏柔和真实
```

## 4.7 逆光发丝光

```text
轻微逆光，角色背后有窗光或灯牌，发丝边缘出现自然光晕，脸部仍然清晰可见，服装金属和宝石配件有细小高光
```

## 4.8 展位彩色灯

```text
漫展展位彩色灯光，背景有蓝色、紫色或粉色灯牌虚化，角色主体保持真实肤色，服装颜色不跑偏，画面有现场热闹感
```

## 4.9 低照度真实噪点

```text
低照度手机拍摄，画面有轻微噪点和运动模糊，真实夜间抓拍感，角色脸部和关键服装细节仍然清楚，不要过度降噪和塑料皮肤
```

## 4.10 清晨柔光

```text
清晨柔和自然光，颜色干净，阴影很淡，角色表情安静，服装材质清晰，背景有轻微空气感和浅色调
```

# 7. 负面提示词模板

注意：如果使用 OpenAI `gpt-image-2`，不要只把下面内容当作独立 negative prompt 堆进去。  
更推荐把负面词改写成自然语言约束，例如「不要生成低俗或性感化姿势，不要混入其他角色的发型和服装」。

## 7.0 gpt-image-2 约束写法

```text
整体端庄自然，非低俗，不性感化。不要暴露化、泳装化、内衣化或擦边姿势。不要生成二次元插画风、CG渲染风、塑料皮肤或过度磨皮。不要出现水印、logo、乱码文字。角色的发型、头饰、服装体系、配件和气质必须保持准确，不要混入其他角色设定。
```

角色防串时可以这样写：

```text
如果当前角色不是芙宁娜，就不要出现芙宁娜的白蓝短发、蓝黑礼帽、枫丹蓝白歌剧服、水滴宝石和水神舞台女王气质。
```

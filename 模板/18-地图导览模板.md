# 地图 / 导览图模板

适合做漫展导览、店铺动线、旅行路线、活动地图。  
重点是“示意清楚”，不是追求真实地图精度。

## 1. 漫展会场导览图

```text
生成一张9:16竖版漫展会场导览图。

主题：
{活动/展馆主题}

版式：
俯视示意地图，包含入口、主舞台、展位区、拍照区、休息区、甜品区、出口。用清晰图标和颜色区分区域，路线箭头从入口连接到各区域。

风格：
干净、可爱但不幼稚，像活动导览手册。背景简洁，区域边界清楚。

文字：
只使用短中文标签，例如“入口”“舞台”“展位”“休息区”。文字清晰可读，不要乱码，不要真实品牌logo。

约束：
这是示意图，不要生成真实城市地图，不要随机街名，不要水印。
```

## 2. 角色打卡路线图

```text
生成一张9:16竖版打卡路线图。

主体：
{角色专属提示词}可以作为小头像或路线终点主视觉出现。

路线：
从“入场”到“展位拍照”“甜品休息”“城市夜景”“返程”，用编号1-5标注。每个点配一个小图标和很短标签。

视觉：
路线清楚，色彩与角色主色一致，背景像简化的商场/展馆平面图。

约束：
如果出现角色头像，发型、头饰、服装配色和气质必须准确，不要混入其他角色元素。文字少而清楚，不要乱码。
```

## 3. 旅行/城市导览海报

```text
生成一张9:16竖版城市旅行导览海报。

内容：
用简化地图展示{城市/街区}的一日路线：咖啡馆、商场、街角、夜景点、地铁口。路线用柔和线条连接。

版式：
上方标题区，中间地图区，下方3个推荐点卡片。地图是示意插画式UI，不需要真实精确比例。

文字：
短中文地名标签，清晰可读；不要乱码，不要真实商标，不要水印。
```

## 4. 避坑

- 地图类不要要求真实精确道路，否则容易乱。
- 只要示意路线和区域，不要生成大量小字。
- 角色头像和主视觉必须重复防串约束。
- 公开使用时避免真实商标、真实店名和误导性路线。

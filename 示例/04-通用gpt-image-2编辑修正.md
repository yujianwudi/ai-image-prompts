# 通用 gpt-image-2 图像编辑修正

## 用途

适合已有图片后做二次修正，例如：

- 换场景但保留角色。
- 修正串角色。
- 修正发型、头饰、服装细节。
- 把图改成更适合公开 README 展示的版本。

## 换场景不换角色

```text
请基于输入图片进行编辑。

保留：
保留人物身份、脸部特征、发型、头饰、服装配色、关键配件、姿势和整体气质。

修改：
只把场景改成明亮的室内漫展展位或甜品店场景，让光线、背景和氛围自然匹配新场景。

不要修改：
不要改变角色身份，不要换发型，不要换服装，不要改变头饰和配件，不要把角色变成其他角色。

风格：
写实手机照片，9:16竖图，真实服装材质，端庄自然，非低俗，适合公开README展示。
```

## 修正串角色

```text
请基于输入图片进行编辑，修正角色设定错误。

当前问题：
图片中混入了错误角色元素，例如发型、帽子、服装配色或气质不属于当前角色。

请修正为：
{正确角色专属提示词}

保留：
保留原图的构图、场景、光线、照片质感和整体姿势。

修改：
只修正发型、头饰、服装配色、关键配件和角色气质，让它们符合正确角色。

约束：
不要改变背景，不要改变镜头角度，不要低俗化，不要性感化，不要生成乱码文字。
```

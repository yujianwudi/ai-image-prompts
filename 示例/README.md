## 使用方法

1. 打开任意示例文件。
2. 复制完整提示词。
3. 如果使用 OpenAI Images API，建议：

```text
model: gpt-image-2
size: 1024x1536
quality: medium 或 high
output_format: jpeg
```

4. 如果要编辑已有图，使用 `04-通用gpt-image-2编辑修正.md`。

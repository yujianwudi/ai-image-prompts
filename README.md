# 生图项目目录

这个项目现在只按两类放：

```text
角色/
模板/
```

## 角色

角色专属提示词都在：

```text
角色/README.md
```

里面放芙宁娜、茜特菈莉、朵莉亚/多莉的角色设定、正向词、反向词和防串提醒。

## 模板

通用固定模板都在：

```text
模板/README.md
```

里面按场景、镜头、灯光、材质、动作、负面词、平台参数分类。

## 推荐使用方式

```text
角色专属提示词 + 1个场景模板 + 1个镜头模板 + 1个灯光模板 + 1个材质模板 + 1组负面词 + 平台参数
```

不要一次性复制所有模板，容易互相污染。

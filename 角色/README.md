## 使用方法

1. 先从这里选一个角色文件。
2. 复制角色的完整正向提示词。
3. 再去 `../模板/README.md` 里挑场景、镜头、灯光、材质和负面词。
4. 最后组合生成。

## 防串原则

角色文件只写角色专属内容。  
不要把通用模板、场景模板、镜头模板全部塞进角色文件里。

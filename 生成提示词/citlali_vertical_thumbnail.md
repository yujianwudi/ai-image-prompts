# 茜特菈莉角色防串教程封面

## 推荐 API 参数

```yaml
model: gpt-image-2
size: 1024x1824
quality: high
output_format: jpeg
output_compression: 85
background: opaque
```

## 提示词

```text
生成一张竖版社媒封面缩略图图像。

主体锁定：
茜特菈莉 Citlali cosplay，淡粉紫色长发，前侧细长辫，黑紫纳塔夜神部落萨满服，冷淡安静、神秘傲娇，像被朋友喊住后不太情愿回头的真实 coser。

必须保留：
- 粉紫长发
- 前侧细辫
- 黑紫纳塔萨满服
- 蓝紫冷色眼睛
- 冷淡神秘傲娇气质

场景环境：
干净的黑紫渐变背景，点缀少量星点和几何纹样。

动作/表情：
她站在画面中间偏右，冷淡看向镜头，左上方预留短标题区。

版式构图：
9:16 竖版封面缩略图，上方短标题区，中间角色半身或三分之二身，下方 2-3 个短标签卡片；主体清楚，背景有层次但不抢主体。

光线色彩：
明亮清楚，有对比但不过度商业硬光，角色和文字区都易读。

材质细节：
角色服装真实，背景干净，有轻微现场感或主题装饰。

文字策略：
短标题不超过 8 个字，标签不超过 4 个字，文字清晰可读；不要乱码、水印、随机英文或真实平台 logo。

安全约束：
端庄自然，非低俗，不性感化，不标题党，不擦边。

防串约束：
- 不要混入芙宁娜的白蓝短发、蓝黑礼帽和枫丹歌剧服
- 不要混入多莉的方形眼镜、金币和紫金商人帽
- 不要混入蓝白贵族歌剧风
- 不要混入低俗或性感化姿势
- 标题建议：角色防串
- 文字少而清楚

质量约束：
- 写实自然，不插画风，不 CG 渲染，不塑料皮肤，不过度磨皮。
- 角色发型、头饰、服装配色、关键配件和气质必须准确。
- 不要混入其他角色设定，尤其不要把茜特菈莉或多莉混成芙宁娜。
- 不要水印、乱码、随机英文、真实平台 logo 或真实品牌 logo。
- 带文字图只使用短标题和短标签，文字必须清晰可读。
```
